Проверить скрытие, удаление, раскрытие, восстановление и прежние счётчики реакций.

## 4. Server Actions и кэш

- [x] 4.1 Реализовать публикацию с серверной валидацией, повтором по ключу запроса и записью события. Тесты проверяют параллельные повторы, конфликт ключа при изменённом тексте, повтор исходного запроса после правки, пустой текст и откат при отказе записи события.
- [x] 4.2 Реализовать правку с транзакционным снимком старого текста и ожидаемой версией. Интеграционные тесты проверяют конфликт вкладок, отсутствие ревизии при одинаковом тексте и атомарный откат при ошибке сохранения ревизии.
- [x] 4.3 Реализовать удаление, восстановление, скрытие и раскрытие с аудитом. Проверить полномочия, причину, неизменность ID и истории, повтор без лишнего события, восстановление скрытой записи и раскрытие удалённой.
- [x] 4.4 Ввести версионированный `CacheKeys` для обработанного Markdown и обновление маршрутов после коммита. Проверить свежесть после правки и отсутствие утечки текста в другой сессии при прогретом кэше после скрытия или удаления.
  Playwright подтвердил смену ключа прогретого Webdis после редактирования и отсутствие скрытого текста и ревизий в ответах гостю и читателю.
